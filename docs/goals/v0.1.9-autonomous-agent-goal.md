# v0.1.9 goal — resilient autonomous coding loop

## Outcome

Orion preserves task intent, criteria, evidence, capability boundaries, and next action across long
coding sessions and repeated Compact cycles. A task ends because its evidence audit passes, the user
cancels it, or a typed recoverable/fatal boundary is reached—not because a default turn counter was
exhausted.

## Acceptance criteria

1. Semantic Compact keeps the canonical transcript append-only, commits only validated Checkpoint
   V2 projections, preserves complete tool groups, retains all mandatory TaskContract/evidence
   bindings, and reaches the 65% safe-input target or pauses with a recoverable diagnosis.
2. Main request, Goal, and subagent paths produce the same typed StopDecision vocabulary. A
   progressing Goal continues beyond 20 automatic continuations; no-progress, blockers, provider
   failures, explicit budgets, permissions, abort, and shutdown remain bounded.
3. HarnessKernel is the deterministic owner of TaskContract V3, criterion/evidence state,
   Capability Profile, ProgressDelta, prompt section manifest, and completion audit.
4. Project context is contained at a canonical root and usage accounting is replay-safe across
   processes.
5. Node 20/22/24, full serial tests, PTY/Print/resume/Goal smokes, and an exact tarball fresh install
   pass on one immutable SHA.
6. `0.1.9` is published only to the separately authorized npm channel. Stable `latest`, Git tag,
   and GitHub Release remain separate decisions and receipts.
