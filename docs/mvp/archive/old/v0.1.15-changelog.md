#### 1. 多模型提供商架构 (Gateway + Vendor 双层设计)

**Route Metadata 系统**:
- `resolveActiveRouteIdFromEnv()` — 从环境变量解析当前路由
- `getTransportKindForRoute()` — 获取路由的 Transport 类型
- `getRouteDefaultBaseUrl()` — 获取默认 API URL
- `getRouteDefaultModel()` — 获取默认模型

**关键设计模式**:
```
用户请求 → Route Resolver → Transport Adapter → API Call → Response Normalization
                ↓
        Provider Selection (Gateway vs Vendor)
                ↓
        Model Catalog Discovery (动态/静态)
```

#### 2. 钩子系统 (Async Hook Registry)

**核心文件**: `src/utils/hooks/AsyncHookRegistry.ts`

OpenClaude 的钩子系统是一个 **异步事件分发框架**：

| 组件 | 功能 | 关键 API |
|------|------|---------|
| `AsyncHookRegistry` | 异步钩子注册/分发 | `registerPendingAsyncHook()`, `checkForAsyncHookResponses()` |
| `hookEvents.ts` | 事件广播系统 | `emitHookStarted()`, `emitHookProgress()`, `emitHookResponse()` |
| `execAgentHook.ts` | Agent 执行钩子 | Agent 生命周期拦截 |
| `execPromptHook.ts` | Prompt 处理钩子 | 提示词预处理/后处理 |
| `sessionHooks.ts` | 会话生命周期钩子 | SessionStart/SessionEnd |
| `ssrfGuard.ts` | SSRF 防护钩子 | URL 访问安全检查 |
| `skillImprovement.ts` | 技能自改进钩子 | AI 驱动的技能优化 |

**Hook 事件类型**:
```typescript
type HookEvent =
  | 'PreToolUse'        // 工具调用前
  | 'PostToolUse'       // 工具调用后
  | 'PrePrompt'         // 提示词处理前
  | 'PostPrompt'        // 提示词处理后
  | 'SessionStart'      // 会话开始
  | 'SessionEnd'        // 会话结束
  | 'Setup'             // 初始化
  | 'Notification'      // 通知事件
  | 'StatusLine'        // 状态栏更新
  | 'FileSuggestion'    // 文件建议
```

**设计亮点**:
- 钩子支持异步执行 (`asyncTimeout` 默认 15s)
- 钩子可输出 JSON 结构化响应
- 钩子有进度轮询机制 (`startHookProgressInterval`)
- 钩子错误不影响主流程 (`Promise.allSettled`)
- 钩子可来自 plugin/skill/user

```typescript
// src/providers/registry.ts

/** Provider 类型 */
export type ProviderKind = 'gateway' | 'vendor' | 'local';

/** Transport 类型 */
export type TransportKind =
  | 'anthropic-native'
  | 'gemini-native'
  | 'openai-compatible'
  | 'local';

/** Provider 定义 */
export interface ProviderDescriptor {
  id: string;                       // 'openai' | 'anthropic' | 'deepseek' | ...
  kind: ProviderKind;               // gateway | vendor | local
  transport: TransportKind;         // transport 类型
  label: string;                    // 显示名称
  defaultBaseUrl?: string;          // 默认 API URL
  defaultModel?: string;            // 默认模型
  authMethod: 'api-key' | 'oauth' | 'none';  // 认证方式
  catalog?: ModelCatalog;           // 模型目录
}

/** Gateway 定义 */
export interface GatewayDescriptor extends ProviderDescriptor {
  kind: 'gateway';
  vendorRouting?: VendorRouting;    // Gateway 到 Vendor 的路由规则
}

/** Vendor 定义 */
export interface VendorDescriptor extends ProviderDescriptor {
  kind: 'vendor';
}

/** 模型目录 */
export interface ModelCatalog {
  models: ModelEntry[];
  discovery?: {
    enabled: boolean;
    endpoint?: string;               // /models 端点
    mapModel?: (raw: unknown) => ModelEntry;
  };
}

export interface ModelEntry {
  apiName: string;                   // API 调用名称
  label: string;                     // 显示名称
  contextWindow?: number;            // 上下文窗口
  maxOutputTokens?: number;          // 最大输出
  supportsVision?: boolean;          // 支持图像
  supportsReasoning?: boolean;       // 支持推理
  default?: boolean;                 // 默认模型
  pricing?: {
    inputPerMTokens?: number;        // 输入价格
    outputPerMTokens?: number;       // 输出价格
  };
}

/** Provider Registry */
export class ProviderRegistry {
  private gateways: Map<string, GatewayDescriptor> = new Map();
  private vendors: Map<string, VendorDescriptor> = new Map();
  private activeRoute: string | null = null;

  /** 注册 Gateway */
  registerGateway(gateway: GatewayDescriptor): void;

  /** 注册 Vendor */
  registerVendor(vendor: VendorDescriptor): void;

  /** 从环境变量解析活跃路由 */
  resolveActiveRoute(env: Record<string, string>): string;

  /** 获取活跃 Provider */
  getActiveProvider(): ProviderDescriptor | null;

  /** 获取 Transport Kind */
  getTransportKind(routeId: string): TransportKind;

  /** 动态发现模型 */
  discoverModels(providerId: string): Promise<ModelEntry[]>;

  /** 获取所有 Providers */
  listProviders(): ProviderDescriptor[];
}
```

### 2. Transport Adapter

**目标**: 实现多协议请求/响应适配

**技术方案**:

```typescript
// src/providers/adapters/base.ts

/** 统一请求格式 */
export interface UnifiedRequest {
  model: string;
  messages: UnifiedMessage[];
  tools?: UnifiedTool[];
  maxTokens?: number;
  temperature?: number;
  stream?: boolean;
  systemPrompt?: string;
}

/** 统一消息格式 */
export interface UnifiedMessage {
  role: 'system' | 'user' | 'assistant' | 'tool';
  content: string | UnifiedContent[];
  toolCalls?: UnifiedToolCall[];
  toolCallId?: string;
}

/** 统一响应格式 */
export interface UnifiedResponse {
  content: string;
  model: string;
  usage: {
    inputTokens: number;
    outputTokens: number;
    cacheReadTokens?: number;
    cacheCreateTokens?: number;
  };
  toolCalls?: UnifiedToolCall[];
}

/** Transport Adapter 接口 */
export interface TransportAdapter {
  transport: TransportKind;

  /** 格式化请求 */
  formatRequest(request: UnifiedRequest): unknown;

  /** 解析响应 */
  parseResponse(response: unknown): UnifiedResponse;

  /** 流式解析 */
  parseStreamChunk(chunk: unknown): Partial<UnifiedResponse>;

  /** 获取 API 客户端 */
  getClient(config: ProviderConfig): unknown;
}

/** OpenAI Compatible Adapter */
export class OpenAICompatibleAdapter implements TransportAdapter {
  transport = 'openai-compatible';

  formatRequest(req: UnifiedRequest): OpenAIRequest {
    // 转换为 OpenAI 格式
    return {
      model: req.model,
      messages: req.messages.map(m => this.formatMessage(m)),
      tools: req.tools?.map(t => this.formatTool(t)),
      max_tokens: req.maxTokens,
      temperature: req.temperature,
      stream: req.stream,
    };
  }

  parseResponse(res: OpenAIResponse): UnifiedResponse {
    return {
      content: res.choices[0].message.content,
      model: res.model,
      usage: {
        inputTokens: res.usage.prompt_tokens,
        outputTokens: res.usage.completion_tokens,
      },
      toolCalls: res.choices[0].message.tool_calls?.map(t => this.parseToolCall(t)),
    };
  }
}

/** Anthropic Native Adapter */
export class AnthropicNativeAdapter implements TransportAdapter {
  transport = 'anthropic-native';

  formatRequest(req: UnifiedRequest): AnthropicRequest {
    // 转换为 Anthropic 格式
    return {
      model: req.model,
      max_tokens: req.maxTokens ?? 4096,
      system: req.systemPrompt,
      messages: req.messages
        .filter(m => m.role !== 'system')
        .map(m => this.formatMessage(m)),
      tools: req.tools?.map(t => this.formatTool(t)),
    };
  }
}
```

```typescript
  event: HookEvent;
  handler: HookHandler;
  priority: number;            // 执行优先级 (小优先)
  timeout?: number;            // 超时 (ms)
  enabled: boolean;
  source: 'builtin' | 'plugin' | 'skill' | 'user';
}

/** Hook Handler */
export type HookHandler = (ctx: HookContext) => Promise<HookResult>;

/** Hook Context */
export interface HookContext {
  event: HookEvent;
  timestamp: number;
  sessionId: string;
  data: Record<string, unknown>;
}

/** Hook Result */
export interface HookResult {
  success: boolean;
  error?: string;
  output?: unknown;
  modified?: boolean;          // 是否修改了上下文
}

/** Hook Registry */
export class HookRegistry {
  private hooks: Map<HookEvent, HookDefinition[]> = new Map();
  private pendingHooks: Map<string, PendingHook> = new Map();

  /** 注册 Hook */
  register(hook: HookDefinition): void;

  /** 注销 Hook */
  unregister(hookId: string): void;

  /** 触发 Hook (顺序执行) */
  async trigger(event: HookEvent, ctx: HookContext): Promise<HookResult[]>;

  /** 触发 Hook (并行执行) */
  async triggerParallel(event: HookEvent, ctx: HookContext): Promise<HookResult[]>;

  /** 触发 Hook (拦截模式，可修改上下文) */
  async triggerIntercept(event: HookEvent, ctx: HookContext): Promise<HookContext>;

  /** 检查异步 Hook 响应 */
  async checkAsyncResponses(): Promise<AsyncHookResponse[]>;

  /** 列出 Hooks */
  listHooks(event?: HookEvent): HookDefinition[];
}

/** Hook 事件广播 */
export class HookEventEmitter {
  private handler: ((event: HookExecutionEvent) => void) | null = null;

  /** 注册事件处理器 */
  registerHandler(handler: (event: HookExecutionEvent) => void): void;

  /** 发送 Hook Started 事件 */
  emitStarted(hookId: string, hookName: string, event: HookEvent): void;

  /** 发送 Hook Progress 事件 */
  emitProgress(hookId: string, output: string): void;

  /** 发送 Hook Response 事件 */
  emitResponse(hookId: string, result: HookResult): void;
}
```

## OpenClaude vs OpenHorse 对比分析 (v0.1.15 视角)

### 可引入的关键设计

| OpenClaude 设计 | OpenHorse 引入方式 | 优先级 | 差异化 |
|----------------|-------------------|--------|--------|
| **Gateway + Vendor 双层** | ProviderRegistry 双层架构 | P0 | 更轻，国产 Provider 优先 |
| **Transport Kind 分类** | 6 种 Transport Adapter | P0 | 简化，核心 3 种 |
| **Route Metadata** | 环境变量路由解析 | P0 | 简化，无复杂校验 |
| **Async Hook Registry** | 轻量 Hook 框架 | P1 | 去掉复杂进度轮询 |
| **Cost Tracker 增强** | 增量计数 + 缓存 | P1 | 简化定价数据库 |
| **inProcessRunner** | 轻量 Agent Coordinator | P2 | 去掉复杂权限同步 |
| **Orama 混合搜索** | 全文 + 向量搜索 | P2 | 可选实现 |

### OpenHorse 差异化竞争优势

| 方向 | OpenClaude | OpenHorse v0.1.15 优势 |
|------|-----------|----------------------|
| **提供商架构** | 15+ 但 Gateway/Vendor 概念复杂 | 简化双层，国产 Provider 优先 (Qwen/DeepSeek/MiMo) |
| **Transport** | 6 种 Transport Kind | 核心 3 种，易于理解 |
| **钩子系统** | 复杂 Async + Progress + JSON | 轻量事件驱动，易上手 |
| **成本追踪** | 完整但依赖 UI | 简化，命令行友好 |
| **部署** | React + Ink + Bun | Node.js + 零 UI 依赖 |
| **国产化** | 间接支持 | 原生支持，定价数据库本土化 |

**核心竞争力**:
1. **国产 Provider 优先** — Qwen/DeepSeek/MiMo 原生支持，定价本土化
2. **简化架构** — 双层 Provider，核心 3 种 Transport，易上手
3. **轻量钩子** — 去掉复杂进度轮询，事件驱动即可
4. **零 UI 依赖** — 纯 Node.js，部署极简
5. **成本透明** — 增强成本追踪，命令行友好

## 风险控制

| 险 | 影响 | 缓解措施 |
|------|------|---------|
| Provider API 不兼容 | 高 | Adapter 模式 + 单元测试覆盖 |

| 钩子性能开销 | 中 | 钩子执行超时 + 并行优化 |
| 成本追踪不准 | 低 | 定期校准 + 手动覆盖 |
| 国产 API 稳定性 | 中 | Gateway fallback 机制 |
