## OpenClaude vs OpenHorse 核心对比

### 架构对比

| 模块 | OpenClaude | OpenHorse v0.1.5 | 差距分析 |
|------|-----------|-----------------|---------|
| **QueryEngine** | 52KB 核心引擎，消息流+工具调用+权限管理 | 无独立引擎，分散在 commands/ | 需要统一引擎抽象 |
| **Tool.ts** | 30KB，buildTool工厂+权限系统+缓存 | 12KB framework/tool.ts | 权限系统需增强 |
| **AppState** | React Context + Store，复杂状态管理 | 简单 Store 类 | 需要增强状态管理 |
| **memdir** | 22KB，MEMORY.md索引+自动记忆+team记忆 | 8KB memory/，向量检索 | 团队记忆缺失 |
| **Skills** | 37KB loadSkillsDir，bundled + mcp + plugin | 6KB skills/，基础加载 | 插件系统缺失 |
| **AgentTool** | forkSubagent + builtInAgents + 协调模式 | 基础 router | Fork/协调缺失 |
| **BashTool** | 27KB，沙箱+安全验证+PowerShell | 基础 exec_command | 安全增强需要 |
| **compact** | 会话压缩服务，自动摘要 | 无 | 会话压缩缺失 |
| **LSPTool** | LSP 集成，符号查询+诊断 | 无 | LSP 支持 P2 |

## P0 (必须) — Agent 协作深化

### 1. Fork Subagent 实现

**目标**: 支持子 Agent 继承父上下文，并行执行任务

**技术方案**:
```typescript
// src/agents/fork.ts
interface ForkOptions {
  inheritContext: boolean;    // 继承对话历史
  permissionMode: 'bubble';    // 权限上浮到父
  tools: string[] | '*';       // 工具池
  maxTurns: number;            // 最大轮次
  background: boolean;         // 后台执行
}

// Fork 子 Agent
- 继承 parent.messages + parent.systemPrompt
- task-notification 模式通知父
- 防递归保护 (检测 FORK_BOILERPLATE_TAG)
```

**实现要点**:
```
src/agents/
├── fork.ts                 # Fork 实现
├── worker-pool.ts          # Worker 池管理
├── coordinator.ts          # 协调器
```

**验收标准**:
- [ ] `/fork <directive>` 创建子 Agent
- [ ] 子 Agent 后台执行，父收到通知
- [ ] 权限请求上浮到父 Agent
- [ ] 防递归 fork 保护

### 2. Worker Pool 实现

**目标**: 支持多 Worker 并行处理任务

**技术方案**:
```typescript
// src/agents/worker-pool.ts
interface WorkerPool {
  workers: Map<string, WorkerState>;
  taskQueue: Task[];
  maxWorkers: number;
  
  submit(task: Task): Promise<TaskResult>;
  broadcast(message: any): void;
  getWorkerStatus(): WorkerStatus[];
}
```

**验收标准**:
- [ ] 支持 max 3 个并发 Worker
- [ ] 任务队列管理
- [ ] Worker 状态追踪
- [ ] 任务超时处理

## 差异化竞争优势

OpenHorse vs OpenClaude:

| 方向 | OpenClaude | OpenHorse 优势 |
|------|-----------|---------------|
| 架构 | React Ink 复杂 | 简洁 CLI，易维护 |
| 依赖 | bun + 大量内部包 | Node.js + 精简依赖 |
| 记忆 | 项目维度 | 向量检索 + 降级方案 |
| Skills | 内置 17 个 | 用户可扩展，简化 |
| Agent | Fork + 协调模式 | 智能路由 + 轻量协作 |
| 配置 | 复杂 settings | YAML + 简化配置 |

**核心竞争力**:
1. **轻量部署** — 单命令安装，无 bun 依赖
2. **向量记忆** — sqlite-vec + 降级方案，兼容性强
3. **简化 Skills** — 用户自定义简单，SKILL.md 格式直观
4. **智能路由** — 关键词+语义分类，轻量高效
