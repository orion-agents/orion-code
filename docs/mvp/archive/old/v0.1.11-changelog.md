### 1. Git 操作验证

**文件**: `src/tools/git.ts`

**问题**: 执行 git push 后未验证工作区是否干净，可能遗漏未追踪文件

**方案**:
```typescript
// git_push 执行后自动验证
async function gitPushVerify(result: string): Promise<ToolResult> {
  // 执行 git status --short 检查
  const status = await execCommand_('git status --short');
  
  // 如果有未提交文件，返回警告
  if (status.output.trim()) {
    return {
      success: true,
      output: result + '\n\n⚠ Warning: Working directory not clean:\n' + status.output,
    };
  }
  return { success: true, output: result };
}
```

### 2. Token 安全提醒

**文件**: `src/core/security-warning.ts`

**问题**: 用户在对话中提供 Token/密钥，Agent 未提醒暴露风险

**方案**:
```typescript
// 检测类 Token 格式
const TOKEN_PATTERNS = [
  /ghp_[A-Za-z0-9]{36}/,          // GitHub Token
  /sk-[A-Za-z0-9]{48}/,          // OpenAI API Key
  /AKIA[A-Z0-9]{16}/,            // AWS Access Key
  /[A-Za-z0-9]{32}-[A-Za-z0-9]{32}/, // Generic secret
];

function detectSecretInMessage(content: string): string[] {
  const detected: string[] = [];
  for (const pattern of TOKEN_PATTERNS) {
    if (pattern.test(content)) {
      detected.push(pattern.source);
    }
  }
  return detected;
}

// 在消息处理时检测并提醒
function warnIfSecretDetected(content: string): void {
  const secrets = detectSecretInMessage(content);
  if (secrets.length > 0) {
    console.log(WARN('⚠ Security Alert: Possible secret/token detected in your message.'));
    console.log(WARN('  Consider revoking and regenerating the token after use.'));
  }
}
```

**验收标准**:
- [ ] GitHub Token (ghp_) 检测
- [ ] OpenAI Key (sk-) 检测
- [ ] AWS Access Key 检测
- [ ] 安全警告显示
- [ ] 测试案例覆盖

// 基于关键词匹配
function matchByKeywords(query: string, memory: MemoryEntry): number {
  const queryWords = query.toLowerCase().split(/\s+/);
  const contentWords = memory.content.toLowerCase().split(/\s+/);
  const matches = queryWords.filter(w => contentWords.includes(w));
  return matches.length / queryWords.length; // 相似度分数
}

### 6. Team Memory 路径安全

**文件**: `src/memory/team-paths.ts`

**方案**:
```typescript
function sanitizePathKey(key: string): string {
  // 检测路径遍历攻击
  if (key.includes('\0')) throw new PathTraversalError('Null byte detected');
  if (key.includes('..')) throw new PathTraversalError('Path traversal detected');
  if (/%2e%2e/i.test(key)) throw new PathTraversalError('URL-encoded traversal');
  if (key.startsWith('/')) throw new PathTraversalError('Absolute path detected');
  
  return key.replace(/[^a-zA-Z0-9_-]/g, '_');
}
```

**验收标准**:
