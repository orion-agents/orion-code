### 关键缺口（阻断"v0.2.23 ready"）
1. **`src/runtime/aggregate-tool-presenter.ts` 缺失**（Slice 4 / P0-B）
   - 方案的头条验收「截图 `batch_read` 4 steps / 3.9 KB 在主 TUI ≤5 行、不显示 raw JSON envelope」依赖 runtime 生成 `ToolAggregateView`。
   - 现状：TUI 折叠策略已就位，但**没有 schema 归一化器把 `batch_read` 变成结构化 step 摘要**，头条能力未接线。
2. **Inspector 三件套缺失**（Slice 6 / P0-B）
   - `transcript-inspector.ts`、`transcript-inspector-layout.ts`、`transcript-inspector-surface.ts` 均不存在。
   - `Ctrl+O` 详情查看（P0 头条交互）尚未实现；`input-ownership.ts` 已存在但无消费方。
3. **eviction 与 compact/resume 专项测试缺失**（Slice 3/5 / P0-A、P0-B）
   - `tui-transcript-eviction.test.ts`、`terminal-compact-resume.test.ts` 不在工作树，方案要求的「10,000 条 committed 后 hot state 有界」「95% Core 自动 compact + 重启/resume 不重复旧上下文」缺乏自动化证据。
