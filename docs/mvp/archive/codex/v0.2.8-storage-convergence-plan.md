# v0.2.8 Storage Convergence Plan

## Summary

v0.2.8 consolidates OpenHorse project-scoped storage so session history,
harness state, typed memory, artifacts, and checkpoints share the same canonical
project identity. The release keeps existing session formats stable and treats
older hash-based memory directories as read-compatible legacy storage.

## Canonical Layout

New writes use the encoded project key produced from the resolved project path:

```text
~/.openhorse/
  projects/
    <encoded-project-path>/
      sessions/
        <sessionId>.json
        <sessionId>.jsonl
        <sessionId>.harness.json
        <sessionId>.index.json
      memory/
        MEMORY.md
        <memory-name>.md
      artifacts/
      checkpoints/
      indexes/
```

Legacy typed memory remains readable from:

```text
~/.openhorse/projects/<sha256-project-hash>/memory/
```

Canonical memory wins when the same memory name exists in both locations.

## Compatibility Rules

- Session metadata, transcript JSONL, harness sidecars, and session indexes keep
  their current schema and project-scoped session path.
- Typed memory writes always go to the canonical `memory/` directory.
- Typed memory reads merge canonical and legacy memory, with canonical entries
  taking precedence by memory name.
- Vector rows written after v0.2.8 use the canonical project key. Search also
  checks the legacy hash key so old rows remain discoverable.
- Artifacts and checkpoints now write to project-level `artifacts/` and
  `checkpoints/`. Cleanup and checkpoint restore still inspect legacy
  `sessions/_artifacts` and `sessions/_checkpoints`.
- `SessionMemory` remains experimental and is not part of the core resume path.

## Validation

Required checks:

```bash
npm run build
npm test -- --runInBand
```

Targeted scenarios:

- `memory_save` writes under the tool context project, not process cwd.
- `memory_recall` finds legacy hash memories and canonical memories.
- `memory_forget` removes project memory and vector record best-effort.
- `/resume` continues to use unchanged session JSONL and harness sidecar files.
- `/doctor` reports legacy storage as a warning, not a fatal failure.
