# v0.2.19 TUI 升级计划

## 当前状态

当前分支为 `v0.2.19`，`package.json` 已在发布验证阶段更新为 `0.2.19`。

OpenHorse 当前主力产品 UI 仍是默认 `terminal` renderer。`tui` 是显式 beta renderer，通过 `openhorse --ui tui` 启动，使用 alternate screen、raw input、frame model、terminal writer 和自己的 layout/reducer 管理输入、状态栏、overlay、transcript 和光标。

已有 TUI 能力：

- 底部受控 prompt、CJK 输入、Backspace、Ctrl+U/Ctrl+W、删除、方向键、Home/End。
- `/` 命令 picker、`@` 文件 picker、`?` 快捷键 overlay、permission overlay、edit preview、session picker。
- PageUp/PageDown 查看 TUI 内部 transcript scrollback。
- `/resume` 选择 session 并恢复 transcript。
- agent 输出过程中继续输入触发 live revision，并以最新目标重启。
- 运行中第一次 `Ctrl+C` 中断，重复 `Ctrl+C` 退出。
- 通过 `AgentRuntimeController` 消费同一套 runtime event/permission/session 协议。
- 自动化覆盖已有 `tui-core`、`tui-ui-state`、`tui-ui-layout`、`tui-ui-runner`、`tui-ui-launch` 和 PTY smoke。

主要差距：

- TUI 仍不具备默认产品 UI 的发布级信心，不能在 v0.2.19 设为默认。
- alternate screen 内部 scrollback 与默认 terminal 的 shell scrollback 体验不同，长输出、resize、复制和历史留存需要更强验证。
- transcript 渲染仍偏基础，长工具参数、长输出、错误、permission 结果和 artifact 提示还没有形成完整工具时间线。
- prompt 仍需要更可靠的多行 viewport、长输入截断提示、IME/manual terminal 实测。
- 初始 PTY smoke 只覆盖核心路径；v0.2.19 已补低高度/窄宽、快速 resize、长流式输出和防 overlap。permission deny 由 runner 单测覆盖，强制信号退出恢复不作为本版承诺。

## 版本目标

v0.2.19 的主题是 **TUI beta 工作台升级**：在不改变默认 `terminal` 路径的前提下，把 `tui` 从"可运行实验 renderer"推进到"可长期试用的 beta 工作台"。

验收目标：

- `terminal` 默认路径行为不回退。
- `tui` 暴露能力与 runtime 语义保持一致，不复制 agent-loop、permission、session、tool、harness 逻辑。
- TUI 能稳定完成普通 chat、slash/file picker、session resume、permission allow/deny、tool ordering、live revision、Ctrl+C 和长输出查看。
- 自动化测试和真实使用记录证明 TUI 在常见终端尺寸、CJK 输入、resize、长输出、工具事件和受控退出下不会破坏光标、prompt 或 terminal restore。

## 非目标

- 不把 TUI 设为默认 UI。
- 不引入 Rust/native TUI rewrite。
- 不把 agent runtime、tool execution、permission policy、session storage 逻辑搬进 TUI。
- 不在 v0.2.19 交付远程 UI、print mode 新能力或 subagent UI。
- 不为了 TUI 改变默认 terminal 的 scrollback-first 产品体验。
