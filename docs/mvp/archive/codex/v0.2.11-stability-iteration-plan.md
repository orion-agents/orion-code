# v0.2.11 Stability Iteration Plan

## Summary

v0.2.11 is a stability convergence release. It keeps `terminal` as the stable
daily-use UI, keeps Ink/TUI as beta renderer checks, and does not introduce a
native TUI/Rust rewrite. The release goal is to harden the current coding-agent
mainline: agent runtime, tools, harness, session/resume, and terminal UI.

## Targets

- Preserve one agent brain with multiple UI shells, as defined in
  `docs/targets/ui-runtime-boundary.md`.
- Improve terminal scrollback UX without changing runtime behavior.
- Keep long-session intent stable across short feedback, compact, and resume.
- Keep tool events ordered, abort-aware, and represented through the shared
  runtime protocol.

## Team Execution

- Main agent owns integration, test selection, and release readiness.
- Plan agent reviews target documents, v0.2.10 plans, and current diffs for
  scope and risk.
- Coding support agent audits terminal/session/harness/tool test coverage and
  recommends concrete gaps.
- Review agent checks final diffs for UI/runtime boundary regressions, session
  compatibility, tool ordering, and missing tests.

## Key Changes

- Terminal UI:
  - `/resume` picker paginates with `n/next` and `p/prev` while preserving
    global numeric selection, id-prefix selection, unique title matching, and
    session size display.
  - Tab completion reports ambiguous candidates instead of appearing inert.
  - `?` renders local terminal shortcuts and is not sent to the model.
  - Scrollback remains append-only; no clearing, alternate-screen behavior, or
    renderer-local agent semantics are introduced.
- Harness:
  - Add regression coverage proving short feedback and verification nudges do
    not overwrite `rootObjective` or bump `taskEpoch`.
  - Keep `/harness explain` and compact behavior centered on root objective,
    active instruction, next action, and verification state.
- Runtime/tools/session:
  - Tool ordering, permission decisions, live revision, abort cleanup, and
    session selection continue through `AgentRuntimeController` and
    `AgentRuntimeInput`/`AgentRuntimeEvent`.
  - No session JSON schema migration is required for this release.

## Validation

- Targeted:
  - `npm test -- --runInBand tests/terminal-ui.test.ts tests/runtime-ui-parity.test.ts`
  - `npm test -- --runInBand tests/session-commands.test.ts tests/session-storage.test.ts`
  - `npm test -- --runInBand tests/harness.test.ts tests/harness-intent.test.ts tests/compact.test.ts`
  - `npm test -- --runInBand tests/tool-scheduler.test.ts tests/query.test.ts tests/tools.test.ts`
- Release gate:
  - `npm run build`
  - `npm test -- --runInBand`
- Manual:
  - `npm run start`
  - Verify CJK input, Backspace, multiline paste, Tab completion, `?`,
    `/resume` pagination, live revision, and Ctrl+C interrupt/double exit.

## Out of Scope

- Native TUI/Rust sidecar.
- Making Ink or TUI the default UI.
- Remote UI or print-mode feature expansion.
- Session schema migration.
- New coding tools unrelated to stability.
