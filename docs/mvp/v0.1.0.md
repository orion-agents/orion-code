# Orion Code v0.1.0

> **Minimal Viable Product — goal-driven coding agent for the terminal.**
>
> Released 2026-07-26 | Branch: `v0.1.0` | Package: `@orion-agents/orion-code`

---

## 1. Overview

Orion Code v0.1.0 is the **initial public release** of the Orion Code agent harness framework. It provides a terminal-based coding agent that wraps LLM APIs with safety boundaries, tool orchestration, session management, and context awareness.

This version represents the **minimal viable product** — the stable subset of capabilities that have been battle-tested through the pre-release development cycle (formerly OpenHorse v0.1.1–v0.2.27, now consolidated and rebranded).

---

## 2. Core Architecture

```
User Input → CLI → Agent Harness → LLM API
                    ├─ Safety Checker
                    ├─ Tool Orchestrator (20+ tools)
                    ├─ Memory System (3 tiers)
                    ├─ Session Manager
                    ├─ MCP Client
                    └─ Context Manager (auto-compact)
```

## 6. What's NOT in v0.1.0

The following capabilities are intentionally excluded from the MVP:

- **Desktop app** — Terminal-only in v0.1.0
- **Web UI** — No browser-based interface
- **Cloud sync** — All data is local
- **Team collaboration** — Single-user only
- **Plugin marketplace** — MCP servers only
- **GPU/local models** — API-based LLM only
- **VSCode/JetBrains extension** — CLI standalone only

## 7. Configuration

```json
{
  "providers": [{
    "id": "my-provider",
    "baseUrl": "https://api.example.com/v1",
    "apiKey": "$MY_API_KEY",
    "protocol": "openai-completions"
  }],
  "models": [{
    "id": "my-model",
    "provider": "my-provider",
    "model": "model-name",
    "contextWindow": 200000,
    "maxOutputTokens": 64000
  }],
  "defaultModel": "my-model",
  "toolConfirmation": "deny",
  "ui": { "renderer": "tui" },
  "subagents": { "mode": "auto", "maxParallel": 4 }
}
```

## 8. Known Limitations

1. **Command conflict**: `orion` binary may conflict with existing npm package `orion@20.0.0`
2. **Ink UI deprecated**: `--ui ink` is deprecated and will be removed
3. **Print mode experimental**: `-p`/`--print` output format may change
4. **Single session**: One active conversation at a time
5. **No offline models**: Requires network access to LLM API

## 9. Migration from OpenHorse

```bash
orion migrate openhorse [--dry-run] [--include-env] [--include-project-files]
```

Migrates `~/.openhorse` → `~/.orion-code` with filename remapping and config key translation. Source data is preserved untouched.
