> 状态：Development Release Candidate

> 包：`@orion-agents/orion-code@0.1.1`
>
> 日期：2026-07-30
>
> Readiness：[v0.1.1 准出报告](../plan/v01.1-release-readiness.md)

## 版本定位

v0.1.1 是 v0.1.0 的可靠性与产品边界收敛版本：

- **TUI** 是默认启动界面和未来面向公众的重点产品；
- **terminal-ui** 只作为 runtime 协议验证、诊断、兼容性排查和必要回退的技术版本；
- **Ink** 已废弃，不再增加产品功能，计划在 v0.2.0 删除；
- Print/Text 与 Print/JSON 继续保持实验性的非交互边界。

本版本不新增第二套 Agent 引擎。所有 renderer 继续消费同一个 runtime、命令、Goal、
权限和结构化事件协议。

## 主要变化

### 共享命令契约

- 命令 registry 增加 execution、risk、renderer scope、availability 和 deprecation 元数据；
- `/help`、TUI palette 和 terminal completion 按 renderer 读取同一 registry；
- `/tool-output`、`/redraw` 作为 TUI-local 命令进入 registry；
- `/goal` 收敛为 `/target` alias，不在默认面板重复展示；
- `/clear` 与 `/exit` 改用 `clear_view`、`shutdown_requested` 结构化事件。

### Goal 与完成门禁

- TUI 和 terminal-ui 的 `/target`、`/goal` 均由共享 `AgentRuntimeController` 路由；
- terminal-ui 不再私有创建 `GoalCoordinator` 或维护独立 continuation loop；
- `budget`、`pause`、`resume`、`edit`、`replace`、`clear --yes` 使用同一解析与状态机；
- 明确要求验证而缺少证据时，不允许宣告完成；
- 连续无证据回复会以 `completion_gate` 安全结束当前 turn，避免模型请求死循环；
- 描述性名称（例如 `markdown render test`）不会被误判成“必须执行测试”。

### 数据安全

- `/storage repair`、`/storage cleanup` 默认预览，写入或删除必须显式 `--yes`；
- `/context-clear --yes` 只清当前内存模型上下文，保存的 session 仍可 `/resume`；
- `/clear-history`、`/reset` 作为隐藏兼容入口迁移到 `/context-clear`；
- `/migrate openhorse` 与 `orion migrate openhorse` 默认 dry-run，只有 `--yes` 才执行；
- `/compact` 明确为可恢复的 state-write，而不是删除型 destructive operation。

### CLI 与迁移

```bash
# 默认公众产品 TUI
orion

# 技术诊断/兼容回退
orion --ui terminal

# 已废弃兼容入口，v0.2.0 删除
orion --ui ink

# OpenHorse 迁移预览（默认不写入）
orion migrate openhorse

# 审阅预览后执行
orion migrate openhorse --yes
```

## 兼容与弃用

| 旧入口 | v0.1.1 行为 | 计划 |
|---|---|---|
| `/goal` | `/target` alias | 保留兼容 |
| `/cost` | 提示迁移到 `/usage` | v0.3.0 删除 |
| `/clear-history`、`/reset` | 隐藏 alias，等价于 `/context-clear` | v0.3.0 删除 |
| `/task`、`/run`、`/chat` | 隐藏旧执行入口 | v0.3.0 删除 |
| `/agents` | 从默认面板隐藏 | 等待真实 runtime task tree |
| `--ui ink` | 明确警告废弃 | v0.2.0 删除 |

## 已知非阻断项

- ESLint 仍报告 143 个历史 warning，但为 0 error；本版本没有把清理整个历史 warning
  backlog 作为补丁发布阻断项。
- `sqlite-vec` 在未安装扩展的环境会回退到文本搜索并输出 warning，这是现有可选能力边界。
- 已废弃 Ink 的完整 PTY 被移出默认发布 Gate；共享 runtime 与普通 Ink 测试仍在主测试运行，
  完整兼容 PTY 可用 `npm run test:ink-compat` 单独执行。
- tarball 仍包含 Ink/React/Yoga 兼容代码；为避免补丁版本破坏兼容，删除安排在 v0.2.0。

## 发布与回滚

发布前必须完成 PR、CI 和代码审查；发布后必须从 npm registry 全新安装并复验默认 TUI。
发现阻断问题时不得覆盖 0.1.1 tarball，应 deprecate 该版本并发布 0.1.2。

回退：

```bash
npm install -g @orion-agents/orion-code@0.1.0
```
