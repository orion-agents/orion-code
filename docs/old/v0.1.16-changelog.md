#### 1. Provider Registry 五层架构

**核心文件**: `src/integrations/registry.ts`

OpenClaude 采用 **五层注册表架构**:

export function resolveActiveRoute(env: Record<string, string>): string {
  // 1. 显式提供商标志
  if (env.CLAUDE_CODE_USE_OPENAI) {
    const baseUrl = env.OPENAI_BASE_URL;
    return resolveRouteFromBaseUrl(baseUrl) || 'openai';
  }
  if (env.CLAUDE_CODE_USE_ANTHROPIC) return 'anthropic';
  if (env.CLAUDE_CODE_USE_QWEN) return 'qwen';
  if (env.CLAUDE_CODE_USE_DEEPSEEK) return 'deepseek';

  if (env.DEEPSEEK_API_KEY && !env.OPENAI_API_KEY) return 'deepseek';
  if (env.QWEN_API_KEY && !env.OPENAI_API_KEY) return 'qwen';

  // 3. 默认
  return env.ANTHROPIC_API_KEY ? 'anthropic' : 'gitlawb-opengateway';

**OpenHorse 简化版** (去掉进度轮询):

```typescript
// src/hooks/async-registry.ts (v0.1.16)
type PendingHook = {
  hookId: string
  hookName: string
  event: HookEvent
  promise: Promise<HookResult>
  timeout: number        // 默认 10s
  startTime: number
}

export class AsyncHookRegistry {
  private pending: Map<string, PendingHook> = new Map();

  // 注册并执行钩子
  async execute(hook: HookDefinition, ctx: HookContext): Promise<HookResult> {
    const timeoutPromise = new Promise<HookResult>((_, reject) =>
      setTimeout(() => reject(new Error('Hook timeout')), hook.timeout || 10000)
    );

    const result = await Promise.race([
      hook.handler(ctx),
      timeoutPromise
    ]);

    return result;
  }

  // 批量执行 (allSettled)
  async executeAll(hooks: HookDefinition[], ctx: HookContext): Promise<HookResult[]> {
    const settled = await Promise.allSettled(
      hooks.map(h => this.execute(h, ctx))
    );
    return settled.map(s => s.status === 'fulfilled' ? s.value : { success: false, error: s.reason });
  }
}
```

#### 4. Model Discovery Service

**核心文件**: `src/integrations/discoveryService.ts`, `src/integrations/discoveryCache.ts`

**OpenClaude 设计**:

```typescript
// discoveryService.ts
export async function discoverModelsForRoute(
  routeId: string,
  options?: DiscoveryOptions
): Promise<ModelCatalogEntry[]> {
  const route = getRouteDescriptor(routeId);
  if (!route?.catalog?.discovery) {
    return route?.catalog?.models ?? [];
  }

  const discovery = route.catalog.discovery;
  const endpoint = discovery.endpoint ?? '/models';
  const baseUrl = route.defaultBaseUrl;

  // 调用 API 发现模型
  const response = await fetch(`${baseUrl}${endpoint}`);
  const models = await response.json();

  // 映射到 ModelCatalogEntry
  return models.map(discovery.mapModel ?? defaultModelMapper);
}

// discoveryCache.ts — 缓存发现结果
export class DiscoveryCache {
  private cache: Map<string, { models: ModelCatalogEntry[]; timestamp: number }> = new Map();
  private ttl: number = 60000; // 60s

  get(routeId: string): ModelCatalogEntry[] | null {
    const entry = this.cache.get(routeId);
    if (!entry || Date.now() - entry.timestamp > this.ttl) {
      return null;
    }
    return entry.models;
  }

  set(routeId: string, models: ModelCatalogEntry[]): void {
    this.cache.set(routeId, { models, timestamp: Date.now() });
  }
}
```

**OpenHorse 实现**:

```typescript
// src/providers/discovery.ts (v0.1.16)
export class ModelDiscoveryService {
  private cache: DiscoveryCache;

  async discoverModels(providerId: string): Promise<ModelEntry[]> {
    // 1. 检查缓存
    const cached = this.cache.get(providerId);
    if (cached) return cached;

    // 2. 获取 Provider
    const provider = this.registry.getProvider(providerId);
    if (!provider?.discovery) {
      return provider?.catalog?.models ?? [];
    }

    // 3. 调用发现端点
    const endpoint = provider.discovery.endpoint || '/models';
    const response = await fetch(`${provider.baseUrl}${endpoint}`);

    // 4. 解析响应
    const rawModels = await response.json();
    const models = rawModels.map(provider.discovery.mapModel || this.defaultMapper);

    // 5. 缓存结果
    this.cache.set(providerId, models);

    return models;
  }

  private defaultMapper(raw: any): ModelEntry {
    return {
      apiName: raw.id || raw.name,
      label: raw.id || raw.name,
      contextWindow: raw.context_window || raw.max_context_length,
    };
  }
}
```

## OpenClaude vs OpenHorse 对比分析 (v0.1.16 视角)

### 可引入的关键设计

| OpenClaude 设计 | OpenHorse v0.1.16 实现 | 简化点 |
|----------------|----------------------|-------|
| **五层 Registry** | 三层 (Vendor+Gateway+Model) | 去掉 Brand、AnthropicProxy |
| **6 种 TransportKind** | 3 种 (anthropic/openai/local) | 去掉 bedrock/vertex/anthropic-proxy |
| **AsyncHookRegistry + 进度轮询** | AsyncHookRegistry + Promise.race | 去掉 startHookProgressInterval |
| **DiscoveryService + Cache** | 完整借鉴 | 保持设计 |
| **Preset 系统** | 完整借鉴 + 国产预设 | 添加 Qwen/DeepSeek/MiMo presets |
| **Route Metadata** | 简化版 resolveActiveRoute | 去掉复杂 validation routing |

### OpenHorse 差异化竞争优势

| 方向 | OpenClaude | OpenHorse v0.1.16 |
|------|-----------|------------------|
| **Registry 复杂度** | 5 层 + 完整校验 | 3 层 + 简化校验 |
| **Transport 类型** | 6 种 | 3 种核心类型 |
| **Hook 进度轮询** | 15s 轮询 + JSON 解析 | Promise.race 超时 |
| **Preset 设计** | 通用 | **国产预设优先** (Qwen/DeepSeek/MiMo) |
| **Discovery** | 完整 | 完整借鉴 |
| **配置复杂度** | 环境变量 + Profile + UI | **环境变量 + Preset 简化配置** |

**核心竞争力**:
1. **三层 Registry** — 简化架构，易于理解和维护
2. **国产 Presets** — DeepSeek/Qwen/MiMo 预配置，开箱即用
3. **简化 Hook** — 去掉进度轮询，Promise.race 超时即可
4. **零 UI 依赖** — 纯 CLI 配置，无需 React/Ink
5. **Discovery 借鉴** — 完整保留动态发现能力
