# v0.1.10 - Compact 服务集成

> **版本定位**: 自动上下文管理 — Compact 服务集成到 CLI/Query
> **发布日期**: 2026-05-27
> **工作量**: 0.5 工作日

---

## 功能概述

将已实现的 Compact 服务集成到 CLI 和 Query 引擎：

1. **手动压缩**: `/compact` 命令手动触发对话压缩
2. **自动压缩**: 对话超过 threshold 条消息自动触发
3. **状态显示**: 状态栏显示 compact 状态

---

## 背景

v0.1.9-plus 已实现 Compact 服务（`src/services/compact/`），但未集成到 CLI 中使用。用户反馈需要自动上下文管理功能。

---

## 实现细节

### 1. `/compact` 命令

**文件**: `src/commands/index.ts`

- 新增 `/compact` slash 命令
- 调用 `getAutoCompact().forceCompact()` 手动触发
- 显示压缩前后消息数量

### 2. 自动压缩触发

**文件**: `src/framework/query.ts`

- 在 `complete` 事件后检查消息数量
- 超过 threshold 时调用 `checkAndCompact()`
- 压缩间隔至少 30 秒

### 3. 测试案例

**文件**: `tests/compact.test.ts`

- `needsCompact` 测试（threshold 边界）
- `compactMessages` 测试（消息数量减少）
- `AutoCompact` 间隔测试（30s 不重复压缩）

---

## API

### `/compact` 命令

```
/compact           # 手动触发压缩当前对话历史
```

### 自动压缩配置

```typescript
// 默认配置
threshold: 50      # 触发阈值（消息数）
maxMessages: 20    # 压缩后保留消息数
interval: 30000    # 压缩间隔（ms）
```
