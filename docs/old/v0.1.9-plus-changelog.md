## Part 4: 自动化服务层 (P1)

**来源**: v0.1.8 roadmap

### 4.1 AutoFix 服务

**目标**: 代码修改后自动运行 lint + test，检测并修复错误

**实现要点**:
```
src/services/auto-fix/
├── autoFixRunner.ts        # 主运行器
├── autoFixHook.ts          # Post-sampling hook
├── autoFixConfig.ts        # 配置 (lintCommand, testCommand, timeout)
└── prompts.ts              # 修复提示
```

**工作流程**:
1. 代码编辑完成后触发 hook
2. 运行 lint 检查
3. 运行 test 检查
4. 检测到错误 → 尝试自动修复
5. 修复失败 → 提示用户

### 4.2 Smart Model Routing

**目标**: 智能路由简单请求到便宜模型，复杂请求到强模型

**实现要点**:
```
src/services/smart-routing.ts (NEW)

├── 简单 (< 160 chars, < 28 words, 无强关键词) → Haiku/Mini
├── 复杂 (含 plan/design/implement/debug) → Sonnet/Opus
└── 配置阈值可自定义
```

### 4.3 Diagnostic Tracking

## 差异化竞争优势

OpenHorse vs OpenClaude:

| 方向 | OpenClaude | OpenHorse 优势 |
|------|-----------|---------------|
| 架构 | React Ink 复杂 (bun) | 简洁 CLI，易维护 (Node.js) |
| 依赖 | 大量内部包 | 精简依赖 |
| 记忆 | 项目维度 | 向量检索 + 降级方案 |
| Skills | 内置 17 个 | 用户可扩展，SKILL.md 直观 |
| Agent | Fork + 协调复杂 | 智能路由 + 轻量协作 |
| 配置 | 复杂 settings | YAML + 简化配置 |

**核心竞争力**:
1. **轻量部署** — 单命令安装，无 bun 依赖
2. **向量记忆** — sqlite-vec + 降级方案，兼容性强
3. **简化 Skills** — 用户自定义简单
4. **智能路由** — 关键词+语义分类，轻量高效
