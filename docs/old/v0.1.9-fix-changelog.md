## Part 1: CLI TUI 渲染修复 (P0)

### 1.1 Issue #26 - 输入框重绘重影问题

**问题描述**: 输入过程中每次重绘都在终端 append 一份 prompt 行，导致严重重影。

**根因分析**: 
- 使用 `process.stdout.write(prompt + buffer)` 而非 ANSI 光标定位 + 行擦除
- 未记录「上一次渲染占了几个视觉行」，擦除不完整

**修复方案**:

```typescript
// src/cli.ts - 使用 ANSI 控制符就地重绘
const CLEAR_LINE = '\x1b[2K';  // 清除当前行
const MOVE_UP = '\x1b[1A';     // 光标上移一行
const MOVE_TO_START = '\r';    // 光标移到行首

function redrawInput(input: string): void {
  // 计算上一次渲染占用的行数
  const prevLines = Math.ceil((lastPromptLength + lastInputLength) / terminalWidth);
  
  // 清除之前的行
  for (let i = 0; i < prevLines; i++) {
    process.stdout.write(MOVE_UP + CLEAR_LINE);
  }
  
  // 移到行首，重新绘制
  process.stdout.write(MOVE_TO_START + getPrompt() + input);
  
  // 记录当前长度
  lastPromptLength = promptLength;
  lastInputLength = input.length;
}
```

**关键文件**:
- `src/cli.ts`: 修改 `redrawInputWithPrompt()` 函数
- `src/ui/command-panel.ts`: 修改 `render()` 函数

### 1.2 Issue #24 - /help 命令面板重复渲染

**问题描述**: 多次 `/help` 导致面板堆叠，未清除上一次渲染。

**修复方案**:

```typescript
// src/ui/command-panel.ts - 在 render() 前清除旧面板
function render(): void {
  // 清除之前的面板
  if (panelHeight > 0) {
    for (let i = 0; i < panelHeight; i++) {
      process.stdout.write('\x1b[2K\x1b[1A');
    }
  }
  
  // 渲染新面板
  const lines = buildPanelLines();
  panelHeight = lines.length;
  process.stdout.write(lines.join('\n') + '\n');
}
```

### 1.3 Issue #25 - CLI 未渲染 Markdown

**问题描述**: Agent 输出 Markdown 原始符号，未做 ANSI 渲染。

**修复方案**: 使用 `marked-terminal` 库渲染 Markdown。

```typescript
// src/ui/markdown.ts - 使用 marked-terminal
import { marked } from 'marked';
import TerminalRenderer from 'marked-terminal';

marked.setOptions({
  renderer: new TerminalRenderer({
    showEscapePrefix: false,
    code: chalk.yellow,
    blockquote: chalk.dim.gray,
    heading: chalk.bold.cyan,
    firstHeading: chalk.bold.magenta,
    hr: chalk.dim,
    listitem: chalk.green,
    table: chalk.cyan,
    paragraph: chalk.white,
    strong: chalk.bold,
    em: chalk.italic,
    codespan: chalk.bgGray.white,
  }),
});

export function renderMarkdownToTerminal(md: string): string {
  // 检测 TTY
  if (!process.stdout.isTTY) {
    return md;  // 非 TTY 返回原始 Markdown
  }
  
  // 检测 NO_COLOR
  if (process.env.NO_COLOR) {
    return md;
  }
  
  return marked.parse(md);
}
```

## Part 2: Git 操作验证修复 (P0)

### 2.1 Issue #18 - Push 未验证 git status

**问题描述**: Push 操作未检查是否有未暂存/未提交的文件，直接声称成功。

**修复方案**: 创建 `git_push` 工具自动执行验证。

```typescript
// src/tools/git.ts (NEW)
export const gitPushTool = buildTool({
  name: 'git_push',
  description: '安全执行 git push，自动验证 git status',
  parameters: {
    type: 'object',
    properties: {
      message: { type: 'string', description: 'Commit message' },
      files: { type: 'array', description: 'Files to add (optional, default all)' },
    },
    required: ['message'],
  },
  execute: async (args) => {
    // 1. git status --porcelain
    const statusResult = await execCommand_('git status --porcelain');
    if (statusResult.success && statusResult.output.trim()) {
      // 有未暂存的变更
      await execCommand_('git add -A');
    }
    
    // 2. git commit
    await execCommand_(`git commit -m "${args.message}"`);
    
    // 3. git push
    const pushResult = await execCommand_('git push');
    
    // 4. 验证
    const logResult = await execCommand_('git log --oneline -1');
    const finalStatus = await execCommand_('git status --porcelain');
    
    if (!finalStatus.output.trim()) {
      return { success: true, output: `Pushed successfully. Latest commit: ${logResult.output}` };
    } else {
      return { success: false, output: 'Push completed but some files remain uncommitted', error: finalStatus.output };
    }
  },
});
```

### 2.2 Issue #23 - Push 未检测远程认证状态

**问题描述**: Push 静默失败，未检测认证状态。

**修复方案**: 增强错误检测和重试机制。

```typescript
// src/tools/git.ts
async function checkGitAuth(): Promise<boolean> {
  const result = await execCommand_('git remote -v');
  if (!result.success) return false;
  
  // 尝试 git ls-remote 检测认证
  const lsRemote = await execCommand_('git ls-remote --heads origin 2>&1', undefined, 5000);
  if (lsRemote.output.includes('Authentication failed') || lsRemote.output.includes('Permission denied')) {
    return false;
  }
  return true;
}
```

## Part 3: Web 工具错误处理修复 (P1)

### 3.1 Issue #20 - web_fetch 重定向处理失败

**问题描述**: 302 重定向返回错误而非跟随重定向。

**修复方案**: 启用 `redirect: 'follow'` 并返回结构化结果。

```typescript
// src/tools/web.ts - fetchUrl 函数修改
async function fetchUrl(url: string, maxRedirects: number = 5): Promise<FetchResult> {
  const response = await fetch(url, {
    headers: { 'User-Agent': 'OpenHorse/0.1.5' },
    redirect: 'follow',  // 关键：启用自动跟随重定向
  });
  
  // ... 处理响应
  return {
    success: response.ok,
    content: await response.text(),
    url: response.url,  // 最终 URL
    redirects: [],      // 重定向链
    code: response.status,
  };
}
```
