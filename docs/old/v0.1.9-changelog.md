### 1. Classifier Approvals 系统

**目标**: Bash 命令自动审批 + Auto-mode 审批追踪

**OpenClaude 参考**: `src/utils/classifierApprovals.ts`

**技术方案**:
```typescript
// src/services/classifier-approvals.ts
interface ClassifierApprovalsService {
  // Bash 分类器审批
  setClassifierApproval(toolUseID: string, matchedRule: string): void;
  getClassifierApproval(toolUseID: string): string | undefined;
  
  // Auto-mode 审批
  setYoloClassifierApproval(toolUseID: string, reason: string): void;
  getYoloClassifierApproval(toolUseID: string): string | undefined;
  
  // 检查状态追踪
  setClassifierChecking(toolUseID: string): void;
  clearClassifierChecking(toolUseID: string): void;
  isClassifierChecking(toolUseID: string): boolean;
  
  // 信号订阅
  subscribeClassifierChecking(callback: () => void): () => void;
}

type ClassifierApproval = {
  classifier: 'bash' | 'auto-mode';
  matchedRule?: string;
  reason?: string;
};
```

**审批规则**:
- **bash classifier**: 命令规则匹配 (如 `npm:*`, `git:*`)
- **auto-mode**: Transcript classifier 自动审批

**验收标准**:
- [ ] Bash 命令审批规则正确匹配
- [ ] Auto-mode 审批原因记录
- [ ] 检查状态信号订阅
- [ ] 审批记录正确清理

```typescript
type Transport = 'stdio' | 'sse' | 'sse-ide' | 'http' | 'ws' | 'ws-ide' | 'sdk';

interface McpTransportConfig {
  // stdio
  stdio: { command: string; args: string[]; env?: Record<string, string> };

  sdk: { client: MCPClient };
}
```

**协议支持**:
- `stdio`: 标准输入输出 (现有)

## 差异化竞争优势

OpenHorse vs OpenClaude:

| 方向 | OpenClaude | OpenHorse v0.1.9 优势 |
|------|-----------|----------------------|
| Classifier | BASH_CLASSIFIER + TRANSCRIPT_CLASSIFIER | 简化审批规则 |
| Auth | OAuth + AWS + Keychain 完整 | 核心 OAuth + API Key |
| Sessions | daemon + bg + worker | 简化会话管理 |
| MCP Transport | 6 种传输协议 | 核心 stdio + SSE + WS |
| Computer Use | macOS GUI 完整 | 简化 CLI 集成 |
| Bash Parser | 15 文件 AST | 简化命令解析 |

**核心竞争力**:
1. **简化基础设施** — 核心功能，无过度复杂
2. **安全认证** — OAuth + API Key + 安全存储
3. **并发管理** — 会话状态追踪
4. **MCP 扩展** — 多传输协议支持
