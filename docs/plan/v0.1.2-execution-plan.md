## 4. Go / No-Go

### Go

- 原始 objective、显式约束、success criteria 跨 compact/restart/resume 恢复；
- continuation 全程 typed goal context，marker 不入 transcript；
- model tool 与 coordinator 按 session 隔离；
- `update_goal complete|blocked` 两阶段，runtime audit 才改变终态；
- 每个 passed criterion 有新鲜、相关、可追溯 evidence；failed/stale/missing 时保持 active；
- accounting 精确，达预算后零新增 provider call；
- pause/interrupt/replace/shutdown 后零 ghost continuation；
- TUI 清晰展示 goal 状态/下一步/预算/audit；terminal-ui/Print parity；
- v0.1.1 additive live-sidecar compat、corrupt recovery、fence-aware rollback playbook 通过；
- build/lint/全量测试/Goal E2E/真实 PTY/tarball/实际 PATH/registry install 全通过；
- PR/CI/review/merge/**tag**/npm/发布后验证各有证据。

### No-Go

- continuation 仍提交 marker 字符串或伪 user message；
- 任一 renderer 拥有私有 GoalCoordinator/audit/scheduler；
- `update_goal` 声称成功但 terminal request 未进入 turn outcome；
- completion 只查 evidence 数量或模型摘要；
- 旧/失败/无关/stale evidence 可关闭 criterion；
- session switch 后 tool 仍指向旧 coordinator；
- restart 后用户不可见时自动执行工具；
- TUI goal 展示破坏 input ownership/scrollback/CJK/paste/Ctrl+C；
- v0.1.1 sidecar 被隐式破坏性重写；
- 只报告 Jest 总量，无长会话/PTY/tarball/registry 证据。
