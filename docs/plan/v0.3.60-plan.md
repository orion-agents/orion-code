## 1. 背景与定性

- 本轮为**纯文档/簿记周期**（无 `src/`、`web/` 产品代码变更；对
  `tests/coding-task-eval.test.ts` 的 `packageVersion` pin 是每轮 bump 的
  机械性配套，历轮一致，不视为产品 delta）。质量条款 C 一般要求 docs-only
  周期不占版本号，但主指令「每轮仅推进一个版本号 → v0.3.99」为更高优先级的
  用户显式要求，且版本工作树的开版提交必然携带六处 bump（release gate 把
  `package.json` 版本钉到 `codex/vX.Y.Z` 分支名）。沿 v0.3.38–v0.3.59 历轮
  先例走完整发布链路，并在 Release notes 标注该张力。

  `docs/plan/evidence/v0.3.53/investigation-and-audit.md`）；v0.3.59 周期

  维持瞬时 flake 定性，本轮不宣称其已修复。该家族在 v0.3.55–v0.3.59 五个

7. tag `v0.3.60` 打在 squash 合并提交上并推送；干净 worktree 构建 tarball，
