# Orion Code v0.1.3 Release Notes — 模型配置一致性

## 概述

本次发布让 `/model` 命令的显示与运行时实际生效的 `modelRegistry` 保持一致
（single source of truth = `modelRegistry`）。修复了来自静态 catalog / legacy 语义的
两处展示偏差：`/model list` 直接读取静态目录、`resolveModelContext()` 未优先使用
已解析的 `resolvedContextWindow`。

## 变更（P0）

- `src/commands/index.ts` → `handleModel()`:
  - 当前模型信息优先从 `ctx.config.modelRegistry` 匹配 profile；Context/Output 显示为
    `resolvedContextWindow` / `resolvedMaxOutputTokens`。
  - `/model list` 从 `modelRegistry.enabledProfiles` 构建（无 registry 时 fallback 到 catalog）。
  - `/model <name|alias>` 优先 `lookupProfile(config.modelRegistry, selector)`
    （id / alias / 唯一前缀）；切换后 `llm.setModel()` 写入 profile 实际 `model`，
    `store.currentModel` 记录 profile id。
  - `/model help` 的 Aliases 合并 catalog + registry aliases。
- `src/services/model-catalog.ts`：静态 catalog 继续作为 metadata/legacy 来源，
  不参与“可切换模型集合”判定（有 registry 时列表只来自 `enabledProfiles`）。

## 测试（P0）

- `tests/status-command.test.ts` 新增 5 个模型配置一致性相关用例（另含 1 个无关的 agent-loop stats 用例）：
  - renders /model list from configured model profiles
    （仅启用 profile、`1.0M ctx`、`(ark)`、`(current)`、`火山方舟`、不含 `claude-opus-4-8`）
  - shows configured profile context in /model info
  - switches /model using registry alias and stores profile id
    （`ark` → `ark-code-latest`，`store.currentModel` = profile id）
  - switches /model aliases to known model ids（catalog alias，`opus` → `claude-opus-4-8`）
  - renders /model help aliases from the shared model catalog
- 现有 `tests/status-command.test.ts` 全部 21 个用例通过；`tsc --noEmit` 无类型错误。

## 验收（DoD）

## 变更 — 模型命令重构（model-command-refactor）

在 P0 一致性基础上，进一步收敛命令面与补全内置 catalog：

### 命令面调整
- `/model`：仅显示当前模型信息（`Current Model`）；保留 `/model <name|alias>` 直接切换。
  删除 `/model list` 与 `/model help`（统一由 `/models` 承接），输入二者会打印移除提示并引导到 `/models`。
- `/models`（新增）：交互式切换模型。交互式渲染器（terminal / tui / ink）返回结构化
  `modelPicker` 请求，由渲染器弹出选择层，选中后回写为 `/model <id>` 重新提交；
  非交互式渲染器（print）直接打印候选列表并提示 `/model <name|alias>`。

### 内置 catalog 补全
- `src/services/model-context.ts`（`BUILTIN_MODELS`）：新增 `ark-code-latest` / `glm-5.2` /
  `kimi-k2.7-code` / `deepseek-v4-pro`（huoshan），`xopdeepseekv4pro` / `xopglm51` /
  `astron-code-latest`（xf-yun），`deepseek-coder`（deepseek），补全 provider 与上下文长度。
- `src/services/model-registry.ts`（`BUILTIN_CATALOG`）：新增上述 API model id 映射（含上下文），
  覆盖 `resolveModelProfile` 的 builtin 回退层；当配置模型（如 `glm-5.2`）未设置 `contextWindow`
  时默认落到 catalog 值（1.0M / 128K）。
- `src/services/model-catalog.ts`（`MODEL_CATALOG`）：扩展至约 26 条，补充 provider / 上下文 /
  alias，供别名与展示元数据使用，并与 `model-context` 元数据保持对齐。

### 交互 picker 机制
复用 `sessionPicker` 管线：`CommandResult.modelPicker` → `chat-controller` 转发
`events.showModelPicker` → `UiEventSink.showModelPicker`（声明为可选方法，避免破坏既有测试 mock）
→ TUI overlay + terminal-ui pending picker；选中解析后回写为 `/model <id>` 命令字符串重新提交。
涉及 `runtime/ui-events.ts`、`runtime/agent-runtime-protocol.ts`、`tui-ui/{state,runner,layout,launch}.ts`、
`terminal-ui/launch.ts`、`ink-ui/screens/ReplScreen.tsx`、`print-ui/launch.ts`、`src/commands/types.ts`、
`src/commands/index.ts`（`handleModel` / `handleModels`）。

### 测试
- `tests/status-command.test.ts`：`/model list`→`/models`（非交互 `Available Models`）、新增 `/models`
  交互 `modelPicker` 断言、`/model` 仅当前信息、`/model <glm-5.2>` catalog 回退（`1.0M tokens (builtin)`）、
  `/model help|list` 移除提示等用例。
- `tests/model-catalog.test.ts`：`deepseek-coder` 对齐 catalog / context 元数据。
- `tests/runtime-ui-parity.test.ts`：`model_picker_requested` 事件归一化分支。
- `tests/command-registry-contract.test.ts`：修复 `mode` 别名 `permissions` 与新增 `permissions`
  命令的冲突（去掉 `mode` 的 `permissions` 别名，保留 `perm`）。

## 风险与回滚

- 风险：静态 catalog 兼容期内 alias 混合行为变化，可能影响未配置模型的历史体验。
- 回滚策略：仅回滚 `src/commands/index.ts` 与相关测试，恢复为 catalog-only 展示逻辑；
  `modelCoordinator` 接入保持待办。

## 延期项（P1 — 未在本发布内完成）

- **ModelCoordinator 接入命令流程**：将 profile 切换、provider 选择、client 检查
  （`pool.getClient`）、compact 前置判断、模型变更事件（`model_changed`）统一到 `/model`
  命令流程，避免继续“字符串切换”与 runtime client 不一致。
- 现状：`src/runtime/model-coordinator.ts` 已具备完整注册表切换能力
  （事务式 prepare/commit/rollback、client 校验、preflight compact、事件发射），但
  `src/cli.ts` 创建后未接入命令层（CommandContext 无 `modelCoordinator` 字段，`handleModel`
  仍走字符串切换）。
- 决策：本发布聚焦 P0（显示一致性 + 回归/新增测试），ModelCoordinator 串联留待下个版本
  统一接入，作为运行时切换唯一路径时一并落地，以降低 `cli.ts` 启动链路回归风险。
