3. **rail 运行状态点样式变化**：terminal rail 的实心绿点（`.rail-status-dot` 纯色）替换为
   `StateDot running`（透明圆环 + pulse，6px + 2px surface 描边）。语义更强（形状通道），
   视觉与旧版不同 —— 属预期增强，需人眼确认观感。

## 6. 建议（非阻断）

1. **补 `prefers-reduced-motion`**：`state-dot-pulse` 与 `notice-in` 建议在
   `@media (prefers-reduced-motion: reduce)` 下禁用/降级（WCAG 2.3.3 精神）。
2. **toast 计数上限的自动清理策略**：超 4 条丢弃最旧目前无提示；若未来高频通知频繁，可考虑
   折叠为「+N」入口。当前域（session-snapshot/transport）低频，无需本轮处理。
3. **主题循环按钮的图形联想**：`monitor`（跟随系统）对部分用户不直观，aria-label 已写清
   当前与下一态；如后续加 tooltip 组件（P2-B）可在该位置优先使用。
4. **classic 风格回归测试缺失**：styles.css 中性 token 无组件测试覆盖（render 层只走
   blocksmith 分支）。低风险，暂记录。
