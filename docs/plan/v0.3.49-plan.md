1. `npm run release:check` 通过（除已知的 better-sqlite3 环境性 Jest 失败，
   以 CI 同名 job 为准；worktree 未提交状态在 commit 后消除）。
2. `tests/coding-task-eval.test.ts` 5/5 绿；`npm run build` 绿。
3. CI（18 项检查）全绿：含 Release gate、build exact tgz、dep-health、harness、
   exact tgz ×3 平台、Web E2E critical journey ×3、Web E2E full suite 三连跑。
   已知常红基线（audit / type-check / Node 矩阵 / full suite）以历史轮次为准判断
   是否为环境性失败；时序 flake 用 `gh run rerun --failed` 处理。
4. 本地 tarball sha256 与 CI web-e2e-primary artifact 的 primary.json
   `tarballSha256` 一致。
5. PR squash 合并后 tag `v0.3.49` 指向 main 合并提交。
6. npm publish 后 registry 直连 curl（`Cache-Control: no-cache`）确认 0.3.49 存在
   且 `dist-tags.latest=0.3.49`，并记录精确入库时间。
7. **GitHub Release v0.3.49 已创建**（`gh release create v0.3.49 --latest`，notes
   含改动说明、质量门禁表、tarball sha256、安装命令）。
8. 无 E2E 场景新增（docs-only 切片），不涉及场景 ID 登记。
9. **质量条款 B（本轮核查）：** main 最新 CI run（41306440869，HEAD `bc4cdbb`）
   conclusion 为 success，无未清偿的 critical journey / audit 红灯；本轮 CI 如出现
