- 对齐一流 coding-agent 的信息层级、运行反馈、键盘效率和可发现性；

- 代码、Diff、日志和工具原始输出保持高密度、专业和可复制。

## 3. 交互与契约

### 3.1 Composer

- 空闲 `Enter` 提交；运行中 `Enter` 保持即时 steering/中断当前 logical request；
- `Shift+Tab` 循环 `BUILD → PLAN → AUTO → BUILD`；运行中只设置下一 logical request；
- 运行中 `Tab` 加入 16 条有界 follow-up queue，不中断当前工作；
- `Esc` 先关闭弹层，否则中断当前工作，不退出 Goal；
- `Ctrl+R` 按当前文本反向搜索历史，重复按键遍历匹配；
- `Ctrl+E` 通过安全临时文件进入 `$VISUAL`/`$EDITOR`；
- 空 Composer `Ctrl+D` 退出；Goal 审计完成后自动回到底层模式，未完成时用 `/goal exit` 放弃。

队列顺序由 shared runtime 持有并通过 `FollowupQueueSnapshot` 投影。Session 切换和
Goal 自动完成或显式退出都会清空队列，避免跨上下文执行；`/queue` 查看，`/queue clear` 清空。

### 3.2 Agent 模式

- BUILD：普通协作模式，遵守当前 permission policy；
- PLAN：完整工具集沿用当前 permission policy，先形成 decision-complete plan，保存后自动启动
  独立执行请求；模式本身不拦截写入、命令或外部工具；
- AUTO：不展示权限或澄清弹窗，由 Agent 基于证据自主判断并持续执行到验证完成；硬 deny、
  protected path、沙箱、灾难性目标与用户明确边界仍然生效，普通 destructive 调用不再二次确认；
- Goal 不进入循环。Goal 活跃时显示 `GOAL · BUILD/PLAN/AUTO`，Shift+Tab 只改变底层模式。

状态栏最左侧的 MODE 不可由 `statusLine` 隐藏。输入区保持透明，仅 MODE、边框与 `›` 使用
模式色：Build `#F8FAFC`、Plan `#58BEFF`、Auto `#FFBD5C`、Goal `#C490FF`。

### 3.3 Orion Pixel

- `orion-pixel` 是默认主题；保留 `classic`、`high-contrast`、`auto`；
- 星际小猎人提供 `ready/thinking/tool/waiting/success/error/paused` 状态；
- 角色只使用安全字符网格，不发送 Kitty/iTerm 图片控制协议；
- NO_COLOR、classic、窄屏自动隐藏 sprite；状态仍通过文字和结构表达；
- motion 配置为 `full/reduced/off`，实现不得超过 4 FPS，空闲不得持续重绘。

### 3.4 配置

`GlobalConfig.ui` 增加可选 `theme`、`motion`、`mascot`、`statusLine` 与语义
`keymap`。未知 enum、状态项和 keymap action 在加载时被删除；renderer 仍是 runtime-only
选择。`/theme`、`/keymap`、`/statusline` 与 `/queue` 进入统一 command registry。

## 4. 验收门禁

1. 单元/契约：主题降级、sprite 宽度、状态优先级、keymap 配置和队列顺序；
2. Golden matrix：24/30/40/60/80/120/154 列，CJK、emoji、多行输入与 NO_COLOR；
3. PTY：resize、paste、scrollback、权限、Tab queue、Enter steering、Esc interrupt、resume、
   `/goal exit`；
4. 性能：stream paint 不超过 30 FPS；空闲零动画重绘；无光标漂移或 scrollback 重写；
5. 发布：Node 20/22/24、全量 Jest、build、lint、tarball clean install 和 packaged PTY。

## 5. 非目标

- 不加入语音、云端任务、完整 Vim、side conversation 或通用后台 shell；
- 不恢复 `/goal clear --yes`；
- 不增加绕过权限协议的 `!` shell；
- 不让像素风进入代码正文、Diff 或原始日志；
- session 扫描性能不与视觉层耦合；其独立目录索引修复保留清晰的存储契约和回归证据。
