### 4.1 `release:check` 覆盖的检查项

`node scripts/release-check.js [--allow-dirty] [--skip-tests] [--skip-pack] [--json]`

1. **版本一致性** —— `package.json` / `package-lock.json`（root + `packages[""]`）/
   两份 README 的安装 pin / 中文 README `（当前版本）`标记；并断言
   `src/product/version.ts` 仍从 `package.json` 解析版本（防 banner/help 漂移）。
2. **CHANGELOG 条目** —— 必须提及当前版本；若无 `v<version>` tag 却标注"已发布"则 FAIL。
3. **`git diff --check`** —— 空白与冲突标记（含已暂存内容）。
4. **工作树洁净度** —— 默认 FAIL，`--allow-dirty` 降级为 WARN。
5. **ESLint** / 6. **`tsc --noEmit`** / 7. **Jest** 全量。
8. **`npm pack --dry-run --ignore-scripts`** —— 校验 tarball 含 `dist/`、`bin/orion`、
   `README.md`、`LICENSE`。用 `--ignore-scripts` 保证只读（否则 `prepack` 会触发 clean+build）。

> **只读保证**：脚本不执行 `git tag`、`git push`、PR、merge 或 `npm publish`。
