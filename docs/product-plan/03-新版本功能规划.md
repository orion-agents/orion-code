# 03 · 新版本功能规划（客户端版 · 代号 "Orion Code Desktop"）

> 目标：将 Orion Code 从 CLI/库 演进为**类 Codex / WorkBuddy 的桌面客户端应用**，达到同等产品体验。
> 策略：**复用已验证的 agent 内核，补齐客户端外壳与产品化交互层**。本文件定义"做什么"，`04` 定义"怎么做"，`05` 定义"何时做"。
> 版本命名建议：`v1.0.0`（客户端首发版）；内核沿用 `v0.2.x` 的能力，在包层级独立标识（建议 `orion-desktop` 包 + 复用 `orion` 引擎包）。

---

## 一、产品愿景与目标

**一句话**：把 Orion Code 的强 agent 内核，"装进"一个开箱即用的桌面工作台 —— 你用自然语言指挥，它直接把事做完，并可视化地把过程与成果交还给你。

**对标指标（达到即"同等效果水平"）**
- 启动到可对话 < 5s（冷启动含原生模块加载）。
- 三模式（Ask/Plan/Craft）覆盖 100% 交互场景，切换零成本。
- 会话恢复率 100%、记忆跨会话可用。
- 多 Agent 协作可在 UI 内可视化编排与监控。
- 技能市场可浏览/安装/更新；兼容现有 `SKILL.md`。
- 高危操作 100% 进入审批/沙箱；无未授权文件访问。

## 二、功能模块规划（按用户旅程）

### M-1 · 桌面外壳与启动（P0）
- 原生窗口（Electron/Tauri，选型见 `04`），含菜单栏、托盘、快捷键。
- 首次启动引导：登录/API Key（支持 BYOK + 可选云端账号）、选择工作目录并**授权**（沙箱根）。
- 自动更新（签名 + 增量）、崩溃上报（脱敏）。
- 复用 `bootstrapRuntime()` 组装引擎；原生模块预构建（关键，见 `04`）。

### M-2 · 富文本对话 UI（P0）
- Markdown 渲染 + 代码高亮 + **内联 diff 视图**（复用 `tool-preview.ts` 思路，升级为可点开/可对比）。
- 图片预览（多模态输入结果）、文件附件卡片、`@` 引用选择器（复用 `@lexiang` 式选择器交互）。
- 流式输出、工具调用过程可视化（tool_call → result 时间线）、中止/继续。
- 草稿历史（Up/Down 回溯）、`Ctrl+R` 历史搜索。

### M-3 · 三模式执行（P0）
- **Ask**：仅问答/审查，不动文件。
- **Plan**：先列分步计划（复用现有 plan 能力），确认后再执行。
- **Craft**：直接动手（默认低风险明确任务）。
- 模式切换零成本；高风险操作（写/删/命令）跨模式统一走审批门（复用 `bash_security` 分级 + `confirmToolUse`）。

### M-4 · 会话与项目管理 UI（P1）
- 会话列表/搜索/标签/恢复（复用 JSONL `session-storage`，加索引层）。
- 项目级工作目录管理 + 授权范围可视化。
- `resume` picker（对标 Codex）、跨项目会话归集。

### M-5 · 文件浏览器与编辑器集成（P1）
- 授权目录树、文件预览、`edit_file` 的 GUI 版（diff + 行级编辑）。
- `@` 文件引用 → 选择器；拖拽文件入对话。
- Git 状态标记（复用 `GIT_TOOLS`）。

### M-6 · 设置与偏好中心（P0）
- 图形化设置：模型与提供商（OpenAI 兼容任意模型 + 默认 fallback）、API Key/账户、外观主题（对标 `/theme`）、权限默认姿态（建议默认 `ask` 而非 `allow`，修正现状第 6 项弱点）、记忆开关、语言。
- 配置文件仍落 `~/.orion-code/orion.json`，GUI 为可视化编辑层（向后兼容 CLI）。

### M-7 · 真·多 Agent 协作（P1，替换现有桩）
- **产品化 Team Mode**：用户可创建多个 Agent 实例、分配角色与权限、在任务发起时选"并行模式"。
- 复用 `runtime/subagents` 的只读调查能力并**扩展为可写协作**（受 Supervisor 预算/权限/轨迹统一管束）。
- 实时监控各 Agent 执行状态、进度、中间结果；结果汇总后统一交付。
- ⚠️ 删除/重构 `src/agents/*` 桩（leader/brain 等），以真实编排实现替换（现状第 3 项弱点修复）。

### M-8 · 技能市场（P1，替换本地扫描）
- 远程市场浏览/搜索/安装/更新（对标 WorkBuddy 技能市场、Codex `plugins`）。
- **兼容现有 `SKILL.md`**（builtin/user/configured/project 优先级保留）。
- 兼容 OpenClaw/ClawHub 生态（若可行）以借力社区。
- 安装隔离、版本管理、一键启用/禁用。

### M-9 · 自动化调度（P2）
- 定时（每天/每周/每小时，RRULE）与一次性指定时间触发（复用现有 cron 表达力，加 GUI 编排）。
- 任务模板、结果投递（文件/连接器）。
- 对标 WorkBuddy"你睡觉它干活"。

### M-10 · 连接器生态（P2）
- IM/办公连接器市场：微信/企微/飞书/钉钉/QQ、腾讯文档/会议/问卷等。
- 远程指令：手机发消息 → 桌面执行 → 回传成果（对标 WorkBuddy）。
- 复用 MCP 作为底层接入标准，连接器 = 预置 MCP server + OAuth。

### M-11 · 记忆可视化（P1）
- 三层记忆（用户级/项目级/云端可选）可视化浏览、编辑、合并冲突提示。
- 复用文件记忆 `MEMORY.md` 索引 + sqlite-vec 向量库；提供"记忆健康度"视图。

### M-12 · 安全与权限中心（P1）
- 工作目录授权可视化、命令分级策略编辑、SSRF 规则查看、轨迹脱敏开关（复用 `bash_security` / `redaction`）。
- **沙箱执行**（Docker / E2B / 等效隔离，对标 Codex 网络禁用沙箱 + WorkBuddy Docker/E2B）：高危/Full-Auto 模式默认进沙箱。

### M-13 · 多模态生成与输入（P1，补现状第 4 项缺口）
- **多模态输入**：截图/设计稿直接拖入对话（对标 Codex 截图、WorkBuddy 截图诊断）。
- **多模态生成**：图像生成、图像编辑、音视频（文本→语音/视频）。
  - 实现路径：新增 `src/tools/image_gen.ts` / `tts.ts` / `video_gen.ts`，对接 OpenAI Images/Speech 或自托管模型（如 Stable Diffusion、本地 TTS）；在客户端内渲染预览与导出。
  - 注意：需在 LLM function-call schema 中注册这些工具，并在 UI 中处理生成结果（图片缩略图、音视频播放器）。

## 三、交互设计

### 3.1 三种模式（与 WorkBuddy 对齐）
| 模式 | 行为 | 默认场景 |
|---|---|---|
| Ask | 仅回答/审查 | 代码理解、Code Review |
| Plan | 先计划→确认→执行 | 重构、架构、多文件 |
| Craft | 直接执行 | 明确低风险任务 |

### 3.2 斜杠命令（扩展现有）
`/model` 切换模型 · `/mode` 切三模式 · `/review` 审查 · `/permissions` 权限 · `/compact` 压缩 · `/skills` 技能 · `/plugins` 连接器 · `/status` · `/theme` · `/clear`。

### 3.3 `@` 引用与拖拽
- 输入 `@` 唤出文件/记忆/技能选择器；选中后以"地址"注入，AI 可随时重读最新版。
- 支持拖拽文件、图片、文件夹入对话。

### 3.4 工具过程可视化
- 每个 tool_call 以卡片呈现：名称、参数摘要、状态（运行/成功/失败）、耗时、结果预览（diff/图片/文本）。可展开看完整 IO。

## 四、典型用户流程（场景旅程）

**场景 A：从 0 到 1 开发作品集网站（对标 WorkBuddy 实战）**
1. 打开桌面客户端 → 选工作目录并授权 → 切到 **Craft**。
2. 输入"创建摄影作品集网站（暗色主题 + 轮播 + 响应式）"。
3. Orion Code 调用文件 API 建结构、生成 HTML/CSS/JS、引入 CDN、写交互逻辑（UI 实时显示 diff 卡片）。
4. 中途"图片被拉伸"→ 用户对 diff 卡片点"采纳/修改" → 自动改 `object-fit: cover`。
5. 交付：文件写入 + 预览链接；会话自动存入"项目：portfolio"。

**场景 B：复杂任务多 Agent 协作**
1. 切 **Plan** → 输入"调研 X 并产出报告"。
2.  planner 拆为：搜集 / 整理 / 校对 三子任务。
3. 用户确认 → 启动 **Team Mode**，3 个 Agent 并行（UI 显示三路进度）。
4. 汇总交付结构化报告。

**场景 C：自动化**
1. 设置中心 → 自动化 → "每天 9 点搜集 AI 资讯生成日报，发企微"。
2. 客户端驻留托盘，到点自动执行，结果回传。

## 六、非功能需求（客户端版）
- **性能**：冷启动 < 5s；长会话（>50 轮）靠 auto-compact + 消息压缩保持响应（修正 WorkBuddy 长对话衰减痛点）。
- **稳定**：复杂/嵌套任务需重规划与异常重试（对标 WorkBuddy 卡死痛点，强化 harness 的 drift guard / completion gate）。
- **安全**：默认权限 `ask`、沙箱隔离、高危拦截、轨迹脱敏、连接器 OAuth。
- **兼容**：CLI 与桌面共享同一份引擎与配置；既有 `SKILL.md` / `mcp.json` 无缝沿用。
- **可移植**：macOS / Windows / Linux 一键安装包 + 自动更新。
