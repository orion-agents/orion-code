# 02 · 竞品调研：OpenAI Codex 与 WorkBuddy

> 调研时间：2026-07-16。来源：OpenAI 官方开发者文档 / Help Center、Codex 开源仓库说明、WorkBuddy 官方站点与腾讯云开发者社区深度评测。
> 目的：提取可复制的核心特性清单，为 Orion Code 客户端化提供对标基准。

---

## 一、OpenAI Codex

### 1.1 产品形态
- **开源本地 CLI**（Rust 编写，`github.com/openai/codex`）+ **云端软件工程 Agent**（集成于 ChatGPT 生态）。
- 系统要求：**Node.js 22+**（2026-03 发布**原生 Windows 应用**，macOS / Linux 原生支持，Windows 此前需 WSL2）。
- 认证：ChatGPT 订阅（Plus/Pro/Business/Edu/Enterprise）或 OpenAI API Key（BYOK）。

### 1.2 核心架构
- **统一 App Server**：一个后端同时驱动 CLI、桌面应用、Web、IDE 扩展 —— 共享配置、历史、技能、线程。
- **Agent Loop**：用户输入 → 模型推理（Responses API）→ 工具调用（Shell / 文件读写 / 测试 / Lint）→ 结果返回 → 下一轮。
- **沙箱执行**：文件操作限定工作目录，网络访问默认关闭；每个任务在隔离环境中并行运行（多个任务互不干扰）。
- **Prompt Caching**：重复请求自动复用缓存前缀，提升性能。
- **Auto-Compaction**：接近 Token 上限时自动压缩对话上下文。

### 1.3 三种审批模式（Approval Modes）
| 模式 | 行为 | 适用 |
|---|---|---|
| **Suggest（默认）** | 只读文件；提议编辑与命令，执行前需人工审批 | 安全探索、代码审查、学习代码库 |
| **Auto Edit** | 自动读写文件；Shell 命令仍需审批 | 重构、重复编辑 |
| **Full Auto** | 编辑与命令均自主执行（网络仍沙箱） | 高度信任的重复性长任务 |

> 进入 Auto Edit / Full Auto 前若目录不在版本控制下，Codex 会警告。

### 1.4 交互模式
- **全屏 TUI**：实时读取仓库、编辑、运行命令；可内联审批步骤（`/approve` / reject）。
- 语法高亮 Markdown 代码块与 diff；`/theme` 预览/保存主题。
- **会话恢复（resume）**：本地存储 transcript，`codex resume` 启动 picker；支持 `--all` / `--last` / `<SESSION_ID>`；云端 exec 也可 resume，保留原始 transcript、plan 历史与审批。
- **远程 TUI（Remote TUI）**：`codex app-server --listen ws://...` 起 WebSocket 服务，`codex --remote ws://host:port` 连接；支持 capability-token / signed-bearer-token 鉴权，非本地强制 wss + TLS。
- **斜杠命令**：`/model`（切换 gpt-5.5 / GPT-5.3-Codex-Spark 等）、`/clear`、`/copy`（Ctrl+O）、`/status`、`/review`、`/features`（feature flags 持久化到 `config.toml`）。
- **多模态输入**：可直接在 composer 粘贴截图 / 设计稿，与 prompt 一并送入模型。

### 1.5 关键能力清单
- 多文件编辑与**统一 Diff** 供审查。
- `AGENTS.md` / `codex.md` 项目指令文件（层级发现，子目录可覆盖/扩展）。
- **MCP 插件系统**：Figma / Jira / CircleCI / GitHub / Linear 等。
- **并行多 Agent 编排**：在隔离的 Git worktree 上并行工作，互不干扰。
- **Code Review**：提交/推送前由独立 Codex Agent 审查。
- **Web Search**、**Cloud tasks**（选环境、应用 diff，不离终端）。
- 模型与 reasoning 可切换（`/model`），支持 feature flags。

### 1.6 产品化要点
- **零配置安装**：`npm i -g @openai/codex` 或 `codex --upgrade`。
- 云端 Agent 返回**可审查的 Pull Request**；本地 CLI 是开源 BYOK。
- 最强档位绑定 ChatGPT Pro / Team / Enterprise 定价。

## 二、WorkBuddy（腾讯云 CodeBuddy 团队）

### 2.1 产品形态
- **桌面客户端**（Win10/11 一键安装包、macOS 拖入 Applications），登录腾讯云账号后**设置与配置云端同步**。
- 入口层：**桌面客户端** + 企微/微信/飞书/钉钉/QQ **远程指令** + 微信小程序（云端沙箱）。
- 定位："把 AI 从 Copilot（副驾）升级成 Agent（主驾），让你从『用电脑』变成『指挥电脑』"。**开箱即用、零门槛**（无需配 env / API Key / Docker）。

### 2.2 运行机制（Agent 闭环）
**感知 → 规划 → 执行 → 交付**。分层：
| 层级 | 职责 |
|---|---|
| 入口层 | 桌面客户端 + 远程指令 + 小程序 |
| 编排层 | 意图理解 → 任务拆解（Plan）→ 多步执行/自主迭代 → 异常重试/重规划；**多 Agent 团队协作（Team Mode）** |
| 模型层 | 内置混元 / DeepSeek / GLM / Kimi 等，OpenAI 兼容格式**可接任意模型**，按任务切 |
| 技能/能力层 | 预置 Skill + 自定义 `SKILL.md` + 兼容 OpenClaw ClawHub 生态；MCP 协议接第三方工具 |
| 执行层 | 本地文件读写、Office 生成、脚本执行、约 30+ 内置工具；连接器调外部服务 |
| 安全层 | 工作目录授权、沙盒隔离、高危指令拦截、连接器鉴权（授权 → 信任 → 验证） |

### 2.3 三种工作模式（核心交互设计）
- **Ask 模式**：纯问答 / Code Review，不动文件。
- **Plan 模式**：先列分步计划，确认后再执行（重构、架构、多文件操作等高风险场景）。
- **Craft 模式**：直接动手（数据清洗、文档生成等低风险明确任务）。
> 设计价值：把「效率」与「安全」的平衡权交还用户，切换零学习成本。

### 2.4 关键能力清单
1. **三层记忆系统**：云端记忆（学习习惯/偏好）+ 用户级记忆（跨项目个人规则，如"文件默认存桌面"）+ 项目级记忆（每项目上下文独立）。越用越懂用户。
2. **多模型自由切换**：混元 / DeepSeek / GLM / Kimi / MiniMax；简单任务用快模型省积分，复杂逻辑切强模型；支持自定义模型提供商接入 GPT/Claude。
3. **技能市场（Skills）**：类似应用商店，内置 20+ 技能（Excel / PPT / 数据分析 / 代码 / 联网搜索 / 图像生成）；**兼容 OpenClaw 技能生态**（GitHub 数十万社区技能包可调用）。
4. **多 Agent 协作（Team Mode）**：同时启动多个 Agent，互相通信、协调进度、分工完成复杂任务（如搜集→整理→校对）。
5. **自动化调度**：定时（每天/每周/每小时）或一次性指定时间触发（如"每天 9 点搜集 AI 资讯生成日报发企微"）。
6. **安全沙箱**：隔离 Docker / E2B 云环境；授权文件夹才可见；高危指令（删除/格式化）拦截或二次确认。
7. **连接器生态**：深度集成微信 / 企微 / 飞书 / 钉钉 / QQ；腾讯文档 / 会议 / 问卷等腾讯系打通；手机发消息远程让电脑干活。
8. **多模态输入/生成**：截图报错直接诊断；图像生成（AI Image Gen）、图像分析、文档/表格/演示生成。
9. **@文件引用**：输入 `@` 唤选择器，AI 拿到"去哪找"的地址，随时可重读最新版。
10. **领域专家 Agent**：内置上百个专家（如股票研究、爆款选题策划），可互相协作。

### 2.5 用户口碑（评测摘要）
- **优点**：真正零门槛、中文理解精准、从"聊天"到"干活"的跨越、多模型灵活、三层记忆越用越懂你、安全设计让人放心。
- **不足**：复杂/嵌套任务稳定性不够（偶发卡死/理解跑偏）；积分消耗快（多模态任务易见底）；PPT/设计能力偏弱（排版美化基础）；长对话质量衰减（>20 轮下降，高版本用消息压缩改善但未完全解决）。

## 三、能力对比矩阵（Codex / WorkBuddy / Orion Code v0.2.19）

| 能力维度 | Codex | WorkBuddy | Orion Code v0.2.19 | 结论 |
|---|---|---|---|---|

| Prompt Cache | ✅ | — | ✅（稳定 system 前缀） | 已达同等，复用 |
| 开源/可自托管 | ✅ CLI 开源 | ❌ 闭源 SaaS | ✅ 开源 | Orion Code 差异化优势 |

## 四、可复制的关键特性清单（用于 Orion Code 客户端化）

**P0（无则不成"客户端"）**
1. 桌面外壳 + 图形前端框架（Electron/Tauri + React DOM）。
2. 富文本对话 UI：Markdown 渲染、代码高亮、diff 视图、图片预览。
3. 三模式执行（对应 Ask / Plan / Craft）。
4. 可视化会话/项目管理（恢复、搜索、标签）。
5. 设置中心（模型、权限、记忆、外观）。

**P1（达到竞品同等体验）**
6. 文件浏览器 + 编辑器集成（授权目录树、diff、@引用）。
7. 真·多 Agent 协作（产品化 Team Mode，非桩）。
8. 技能市场（远程浏览/安装/更新，兼容现有 SKILL.md）。
9. 多模态生成管线（图像/音视频）+ 多模态输入（截图）。
10. 安全沙箱（Docker/E2B 或等效隔离）+ 高危拦截。
11. 自动化调度 UI（定时/一次性）。

**P2（生态与差异化）**
12. 连接器市场（IM/办公/腾讯系等）。
13. 云端同步/账户/计费（若走 SaaS）。
14. 远程指令（手机 → 桌面执行）。
15. 统一 App Server 架构（借鉴 Codex，一份后端驱动 CLI/桌面/Web）。

**Orion Code 已有可复用资产（勿重写）**：Agent Loop（query/tool-scheduler/auto-compact）、MCP 集成、多层记忆、Skills 系统、安全分级与 SSRF、Subagents 只读调查、SDK 表面、OpenAI 兼容 LLM 层与 fallback。
