# Orion Code v0.1.0 → v0.1.9 回归测试计划

## 使用说明

本测试计划覆盖 Orion Code 从 v0.1.0 到 v0.1.9 所有已实现功能点。每个测试用例包含：

- **TC-ID**: 测试用例编号
- **模块**: 所属功能模块
- **来源版本**: 引入该功能的版本
- **测试步骤**: 具体操作
- **预期结果**: 通过标准
- **状态**: ⬜ 未测 / ✅ 通过 / ❌ 失败
