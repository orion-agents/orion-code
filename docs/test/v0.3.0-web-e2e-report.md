## 1. Result

One frozen npm tarball passed the complete 22-scenario browser qualification three consecutive
times and the 18-scenario critical qualification on Node 20, 22 and 24. The assembled, fail-closed
Web E2E receipt is `GO`.

This section records immutable historical evidence. Node 20 has since left the v0.3 support
contract and Node 26 has entered it. The old receipt does not qualify the current matrix; the new
22.12/24/26 exact-tarball evidence is recorded in the
[current compatibility report](v0.3.0-node-runtime-compatibility-report.md).

These are not mocked component tests. Real Google Chrome drove the clean-installed `orion web`
binary through the public UI, HTTP/SSE Host, production Runtime, ToolGateway, permission policy,
filesystem and command tools, MCP transport, Settings repository/coordinator and durable
thread/session stores. Only the external model boundary used a deterministic loopback
OpenAI-compatible streaming provider.

## 7. Failure and repair ledger

Failures were preserved as `NO_GO` evidence and repaired without force-click, skip, retry or weaker
product assertions.

| ID       | Observed failure                                                                              | Repair and lasting guard                                                                                           |
| -------- | --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| WEB-F001 | Static-root symlink could expose an outside sentinel.                                         | Canonicalize root/candidate and enforce the boundary; final attack is HTTP 403.                                    |
| WEB-F002 | Real large ToolGateway output had no inspectable artifact.                                    | Persist bounded StepSnapshot artifact data and byte-page it without exposing backing paths.                        |
| WEB-F003 | Approval/transcript projection races produced stale or duplicate UI.                          | Resolve pending state only on explicit decision and keep the thread projection authoritative.                      |
| WEB-F004 | PLAN execution could be scheduled twice.                                                      | Remove the legacy follow-up when the production session runner owns the request.                                   |
| WEB-F005 | Node 20 destroyed a backpressured SSE response and replayed forever.                          | End replay cleanly and track request abort separately; final Node 20 run is 18/18.                                 |
| SET-F001 | Session rename targeted a stale row after creation.                                           | Wait for active identity/count convergence and relocate via accessibility semantics.                               |
| SET-F002 | Early null bootstrap after Host restart left the composer disabled.                           | Diagnostics no longer creates a hidden Session; recovery converges on new bootstrap/workbench state.               |
| SET-F003 | Tool cards lost authorization provenance and receipt digests.                                 | Validate canonical durable receipt, project typed authorization, and narrowly whitelist it through Host redaction. |
| SET-F004 | Reject test incorrectly expected a second provider request.                                   | Assert production semantics: pending clears, turn terminates, file stays absent and Runtime becomes idle.          |
| SET-F005 | Expected 409 and intentional EventSource cancellation looked like unexplained browser errors. | Register exact one-shot method/path/status/error expectations; any additional event still fails.                   |
| SET-F006 | CDP pinch zoom preserved a 640 px layout and was mistaken for reflow.                         | Use equivalent 320 CSS px + DPR 2 and retain normal pointer, overflow, focus and axe assertions.                   |
