# Orion Code v0.3.4 稳定化测试计划

- 版本：v0.3.4
- 被测对象：从 clean source 构建一次、随后在空 prefix 安装的同一 npm tgz
- 浏览器：真实 Google Chrome，核心旅程不启用 `bypassCSP`
- Runtime：Node 22.12.0、24.0.0、26.0.0

## 测试目标

1. 证明跨 Workspace、跨 Session 和并发命令不会误写或串台；
2. 证明敏感资源不会从 Files、Git、tool details、命令输出、SSE、snapshot 或证据文件泄露；
3. 证明 Terminal 在 Unicode 分片、reconnect、backpressure 与 exit 竞态下保持有序；
4. 证明 release receipt 对失败 canary、重复证据和缺失矩阵 fail closed。

## 测试金字塔

- 单元：redaction、cursor、binary、surrogate、receipt/fact 真值表、review totals；
- 集成：Host 路由 + Controller Context CAS、真实 Git/file fixture、真实 loopback WebSocket；
- E2E：installed tgz + deterministic provider + Chrome，两页/多 Session/断线恢复；
- 发布：同 tgz 的 Node floor matrix、三次 primary、三条 runtime 和 final receipt。

## 证据要求

- 每个 E2E 运行使用独立 HOME、config、tmp、workspace、port 和证据目录；
- 只记录相对路径、版本、digest、cursor、sequence、计数和裁剪 PNG，不记录 nonce、header、prompt、绝对路径或配置内容；
- expected network failure 必须逐条验证 method/path/error，再从总计中扣除；
- 截图、manifest、artifact receipt、runner digest 和 installed target digest 必须纳入最终 manifest digest；
- 任一 skip、timeout、console/page error、HTTP 5xx、secret finding、dropped event、orphan process 都失败。
