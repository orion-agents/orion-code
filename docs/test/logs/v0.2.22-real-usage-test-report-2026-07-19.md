## 已知问题 (Known Issues)

1. **破损 meta 文件** — `e0e2caf8-...runtime.json` 无有效 id。推测来自异常的 session 写入（崩溃或 power loss）。不影响正常 session，但建议加清理命令 `/session gc`。

2. **Compact checkpoint 未触发** — 所有 session 无 `.compact.json`。实际使用需足够长的对话才会触发 compact（默认阈值 50 条左右）。当前 session 最长 50 条，但可能接近但未到达触发点。建议手动验证 `/compact` 命令。

3. **Memory paths 为空** — 项目目录无 OPENHORSE.md / OPENHORSE.local.md。Memory 系统依赖这些文件的存在，建议在项目根目录创建指导文件。
